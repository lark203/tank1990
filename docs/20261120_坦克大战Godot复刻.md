## 实现方案

- 直接复制原版 PNG/WAV/TMX 到 `assets/`，像素过滤 Nearest（480×54 的 `logo.png`、39×39 坦克、50×50×9 帧爆炸、4 帧钢盔、2 帧水面等全部原样复用）。
- **不用 Godot 物理引擎**：用 `TankWorld` 扁平实体表 + 手工 AABB，逐帧复刻 FXGL 碰撞处理器顺序与语义（含逐像素回退移动、同阵营忽略、子弹等级破墙规则、同帧多地形处理）。
- 程序化生成全部 UI（Control/Button/Sprite2D），便于像素级控制位置与 FXGL 默认样式差异。
- 主菜单坦克弹入用 `Tween.TRANS_ELASTIC + EASE_OUT` 对齐 FXGL `Interpolators.ELASTIC.EASE_OUT`。
- 为可重复验证，`main.gd` 支持 `--shot=路径 --delay=秒 --action=enter|construct --post=秒 --sim` 自截图与自动按键参数。

### 踩坑记录（供后续参考）

- **Godot Button 状态色**：只覆盖 `font_color` 不够，hover/pressed/focus 各有独立 theme color，必须逐一覆盖，否则悬停时回落到默认白色。
- **自截图与窗口尺寸**：`window_width_override` 是窗口外框尺寸，Godot 4.7 自截图 `get_viewport().get_texture()` 在有 stretch 时返回窗口纹理（含外框留白），因此截图里会看到约 30px 灰边，这是捕获机制的 artifact，不影响实际游玩画面。
- **headless `--script` 不可靠**：`extends SceneTree` 的探针脚本在 `_init()` 里实例化主场景常卡死/取不到节点，改用有头运行 + `main.gd` 临时命令行钩子打印断言更稳定（钩子用完即还原）。
